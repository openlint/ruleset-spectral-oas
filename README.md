# Legacy Spectral OpenAPI ruleset

This package preserves the complete legacy `spectral:oas` ruleset, including
the documentation-style rules that are not part of the OpenLint OpenAPI core
ruleset.

The OpenLint CLI retains the `spectral:oas` spelling for compatibility. To
extend the package directly, use:

```yaml
extends: "@openlint/openlint-ruleset-spectral-oas"
```
